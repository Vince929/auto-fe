# 路由配置表

> ⚠️ **维护规则**：每当路由配置发生变化（新增/删除/修改路由）时，必须同步更新本文档。

## 路由结构说明

- **路由配置文件**：`[src/router/index.ts 或 src/App.tsx]`
- **路由库**：`[React Router DOM v6 / Vue Router v4 / ...]`
- **路由模式**：`[History（路径模式）/ Hash（哈希模式）]`
- **路由结构**：`[单入口 / 多入口]`

> 完整路由格式：`/[前缀]/[模块]/[页面]`
